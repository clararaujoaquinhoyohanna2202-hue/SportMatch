# SportMatch

Landing page para organização de rachas esportivos, desenvolvida em **React + Vite**.

## Funcionalidades

- Página inicial com apresentação do app
- Listagem de rachas disponíveis
- Busca de rachas por esporte/local
- Modais de login, contato e criação de racha
- Layout responsivo com identidade visual própria

## Como rodar o projeto

```bash
# instalar dependências
npm install

# rodar em ambiente de desenvolvimento
npm run dev

# gerar build de produção
npm run build
```

## Tecnologias

- React 19
- Vite
- Lucide React (ícones)
- CSS modular por seções

## Estrutura

```
src/
  components/   # componentes da interface
  data/         # dados dos rachas
  styles/       # estilos por seção
  App.jsx
  main.jsx
```
